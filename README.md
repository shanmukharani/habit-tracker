# Habit Tracker

A habit tracking application built with React, TypeScript, and Tailwind CSS that helps users build consistent routines and monitor their daily progress.

## Features

- **Habit Management:** Add and delete habits.
- **Daily Tracking:** Mark habits as completed for specific dates.
- **Streak Tracking:** Monitor consecutive days of habit completion.
- **Persistent Storage:** Save habits and completion records in browser local storage.
- **Responsive Interface:** Track habits through a clean, user-friendly interface.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Browser Local Storage
- Vite

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/shanmukharani/habit-tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd habit-tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Project Purpose

Built to practise React component design, TypeScript props and types, state management with React hooks, reusable components, and browser-based data persistence.
